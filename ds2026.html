Course Description

This course introduces the fundamental concepts of data structures and algorithm analysis with emphasis on designing efficient computational solutions. Students learn the representation and implementation of linear and non-linear data structures including arrays, linked lists, stacks, queues, hash tables, heaps, binary search trees, AVL trees, Red-Black trees and B-Trees.

The course also covers dictionary operations, searching, sorting, priority queues, order statistics, graph representations, Breadth-First Search (BFS) and Depth-First Search (DFS). Students develop the ability to analyze algorithm efficiency using asymptotic notations and recurrence relations and to select appropriate data structures for solving computational problems efficiently.

Course Outcomes

After successful completion of the course, the student will be able to:

  1. Analyze the time and space complexity of algorithms using asymptotic notations and recurrence relations.
  2. Select and implement appropriate linear and non-linear data structures to solve computational problems efficiently.
  3. Design and analyze fundamental algorithms for searching, sorting, hashing and order statistics.
  4. Apply advanced tree-based data structures including AVL Trees, Red-Black Trees, Heaps and B-Trees to support efficient dictionary operations.
  5. Represent graphs using suitable data structures and apply graph traversal algorithms such as Breadth-First Search (BFS) and Depth-First Search (DFS).
